# 守岸人的港湾 · 个人主页

一个纯静态的蓝色系个人主页：开场时守岸人的发光蝴蝶从两侧飞到中间 → 出现「进入」按钮 → 进入后播放背景音乐、显示主页内容。

没有框架、没有构建步骤、没有依赖，直接上传到 GitHub Pages 就能跑。

---

## 一、目录结构

```
.
├── index.html          # 页面本体（要改的文字基本都在这里）
├── css/
│   └── style.css       # 全部样式：蓝色主题、蝴蝶动画、布局
├── js/
│   └── main.js         # 进入逻辑、背景音乐开关、滚动动画
├── assets/
│   ├── bg.jpg          # 背景图（已放入你给的那张）
│   ├── bgm.mp3         # 背景音乐（已放入，1 分 22 秒）
│   ├── avatar.jpg      # 头像（当前是占位图，换成你自己的）
│   └── favicon.svg     # 浏览器标签页小图标
├── .nojekyll           # 让 GitHub Pages 不做 Jekyll 处理（必需，别删）
├── .gitignore
└── README.md
```

## 二、本地预览

**方式 A（推荐）**：在本文件夹里开一个本地服务器

```bash
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

**方式 B**：直接双击 `index.html`。页面和背景音乐都能用，但某些浏览器对本地文件的限制更严，遇到怪问题就用方式 A。

## 四、上传到 GitHub Pages

### 1. 建仓库

登录 GitHub → 右上角 `+` → **New repository**。

仓库名有两种选择：

| 仓库名 | 最终网址 |
| --- | --- |
| `<你的用户名>.github.io`（推荐） | `https://<你的用户名>.github.io/` |
| 其他名字，例如 `my-home` | `https://<你的用户名>.github.io/my-home/` |

> 注意：`<你的用户名>` 必须和你的 GitHub 用户名完全一致（大小写都要对）。

可见性选 **Public**（私有仓库要 GitHub Pro 才能用 Pages）。**不要**勾选 Add a README，建一个空仓库。

### 2. 上传文件

**方式 A：网页上传（最简单）**

在仓库页面点 **Add file → Upload files**，把 `index.html`、`css`、`js`、`assets`、`.nojekyll` 一起拖进去，然后 **Commit changes**。

> `.nojekyll` 是隐藏文件，Windows 资源管理器里要先开启「显示隐藏的项目」才看得到。
> 如果它没传上去，页面有可能 404 或样式丢失——所以在 Putty/命令行方式里更省心。

**方式 B：Git 命令行（推荐，之后改起来方便）**

```bash
cd 这个文件夹
git init
git add .
git commit -m "init: 守岸人的港湾"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

### 3. 打开 Pages

仓库 **Settings → Pages**：

- **Source**：`Deploy from a branch`
- **Branch**：`main`，目录选 `/ (root)`
- 点 **Save**

等 1～2 分钟，刷新页面，顶部会出现你的网址。手机浏览器也打开确认一下。

### 4. 以后怎么更新

改完文件后：

```bash
git add .
git commit -m "更新自我介绍"
git push
```

推送后 1 分钟左右自动生效。**如果没变化，先按 `Ctrl + F5` 强制刷新**（浏览器缓存很常见）。

## 五、常见问题

**Q：点「进入」没反应？**
现在按钮、整个开场层、以及键盘 `Enter` / `空格` / `Esc` 都能进入，所以正常情况下不会卡住。
如果还是点不动，按 `F12` 打开控制台看有没有红色报错——那通常是预览器屏蔽了脚本（比如某些 App 内置预览）。把文件夹用浏览器直接打开即可。

**Q：进入后没有音乐？**
先看右下角按钮上写的字，它会直接告诉你原因：

| 按钮显示 | 含义 | 怎么办 |
| --- | --- | --- |
| `音乐开`（音条在跳） | 正在播放 | 那就是**系统音量或标签页被静音**了：右键浏览器标签页 →「取消静音网站」，再检查 Windows 音量合成器 |
| `音乐关` | 被关掉了 | 点一下按钮即可。**关掉的选择会被记住**：上次关过，下次进来不会自动响 |
| `缺少 bgm.mp3` | 文件没找到 | 确认 `assets/bgm.mp3` 就在这个路径下，文件名**全小写** |
| `音乐不可用` / `音频损坏` | 文件读不了 | 换一个音频文件；或按 `F12` 看控制台的错误码 |

最快的自查：直接双击 `assets/bgm.mp3`，能听到声音就说明文件和系统音频都没问题。

**Q：点「进入」没反应，按钮也不出现？**
这说明页面里的 **JavaScript 没有运行**（多半是某个 App 的内置预览器屏蔽了脚本）。用浏览器直接打开这个文件夹里的 `index.html` 即可。正常情况下面板会给出提示条说明原因。

**Q：背景图不显示？**
同样先检查 `assets/bg.jpg` 是否存在、文件名是否全小写。路径大小写在 GitHub Pages 上是区分大小写的。

**Q：页面卡顿？**
动画只用了 `transform` 和 `opacity`，一般不会卡。若确实卡，把 `css/style.css` 里 `.intro__bg` 的 `blur(10px)` 去掉或调小，模糊是最费性能的一项。

**Q：关于版权**
背景图（守岸人立绘）和背景音乐如果来自游戏或网络，放进 **Public** 仓库等于公开传播，有版权风险。自己看没问题；想更稳妥的话，可以换成自己拍摄/绘制的素材，或把仓库设为 Private（需要 GitHub Pro 才能开 Pages）。

## 六、桌宠（Q 版守岸人）

页面左下角那只 Q 版守岸人用的是「**纸片人分层**」做法：把立绘拆成 上半身 / 下半身 / 左腿 / 右腿 / 闭眼 / 咬口 六层叠在一起，各层用自己的旋转支点单独动，所以不会像「一块纸板平移」那样僵硬。

| 行为 | 说明 |
| --- | --- |
| **导航** | 点她弹出菜单：首页 / 自我介绍 / 兴趣与日常 / 联系我；菜单里会高亮你当前所在的版块 |
| **眨眼** | 闭眼层像**眼皮从上往下压**（0.07 秒闭上、0.13 秒睁开），每 1.5～4.5 秒一次，偶尔连眨两下 |
| **自己走动** | 每 7～16 秒换位置。走动时**四条线一起动**：双腿前后迈（±6.5°）、髋部左右摆（±1.5°）、上半身反向摆（±1.6°）、整体按步频起伏；往左走时整体镜像转身 |
| **吃西瓜** | 每 20～50 秒一次，分三阶段：咬一口 → 咬三口 → 吃掉大半个（西瓜明显变小），同时上半身反复点头咀嚼，中间说「啊呜…」，吃完说「西瓜很甜。」 |
| **待机** | 呼吸起伏 + 整体轻晃 + 上半身缓慢左右摆动（6.5 秒一轮） |
| **可拖动** | 按住拖到任意位置，位置记在浏览器里，刷新后还在原处 |
| **安静模式** | 菜单底部的蓝色开关。打开后她**不再自己走动、不再主动说话、也不吃西瓜**（点她导航依然可用）；状态会被记住 |
| **系统偏好** | 系统开启「减少动态效果」时，走动 / 吃西瓜 / 待机晃动都会停下（眨眼保留，否则就像张静止图） |

## 七、想要更多效果时

改配色：`css/style.css` 顶部 `:root` 里的 `--blue-*` 变量控制全站蓝色深浅，改一处全站生效。
改蝴蝶：`index.html` 里 `<div class="intro__flies">` 下的每个 `<span class="bf">` 就是一只蝴蝶，`--delay`（出场时间）、`--s`（大小）、`--cx/--cy`（汇聚到哪个位置）都能单独调；复制一整块就能多加一只。
